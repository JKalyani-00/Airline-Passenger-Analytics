# Airline Passenger Experience & Satisfaction Dashboard

## Project Overview

This project analyzes airline passenger experience and satisfaction using Power BI, Excel, and DAX.

The dashboard provides insights into passenger satisfaction, service ratings, travel class, customer type, and flight delays.

## Tools Used

- Power BI
- Excel
- DAX

## Dataset

Airline Passenger Satisfaction dataset containing passenger survey responses, service ratings, flight distance, and delay information.

The training and testing datasets were combined for analysis.

## Dashboard Pages

### 1. Passenger Overview
- Total passengers
- Satisfied passengers
- Satisfaction rate
- Average flight distance
- Average departure delay
- Average arrival delay
- Satisfaction by travel type, class, customer type, and gender

### 2. Service Experience
- Wi-Fi rating
- Online boarding rating
- Seat comfort rating
- Cleanliness rating
- Satisfaction analysis by service ratings

### 3. Flight Delay Analysis
- Passenger satisfaction by delay group
- Average departure delay by class
- Average arrival delay by class
- Satisfaction rate by departure delay

## DAX Measures

- Total Passengers
- Satisfied Passengers
- Satisfaction Rate
- Average Flight Distance
- Average Departure Delay
- Average Arrival Delay

## Key Skills Demonstrated
